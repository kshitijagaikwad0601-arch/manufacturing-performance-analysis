# Manufacturing Performance Analysis

## Project Objective
This project analyzes manufacturing performance data to identify production inefficiencies, downtime drivers, batch-level performance issues, and operational bottlenecks.

## Tools Used
- Microsoft Excel
- PostgreSQL
- Tableau

## Analysis Performed
- Production performance analysis
- Downtime analysis
- Batch performance analysis
- Machine/product-level analysis
- Pareto analysis of downtime causes
- Identification of operational bottlenecks

## Dashboard
An interactive Tableau dashboard is currently under development.
